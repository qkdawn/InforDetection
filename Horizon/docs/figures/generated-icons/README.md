# Generated figure icons

These project-bound bitmap assets were generated with `gpt-image-2` through the
configured Bee API image channel on 2026-08-06. They use one shared scientific
editorial prompt direction: compact paper-cut depth, muted mineral blue and teal,
warm red and ochre accents, dark graphite edges, no labels, and no logos.

The transparent assets were generated on a flat green background and processed
with the installed `imagegen` chroma-key removal helper using a soft matte and
despill. `acquisition.png`, `evidence-enrichment.png`, and `delivery.png` are kept
as intentionally framed white-background scientific illustration cards because
the model did not honor the chroma-key background on those three subjects.

`prompts.jsonl` records the complete batch prompt set. The main figure source is
`../game-inspiration-pipeline.R`.
