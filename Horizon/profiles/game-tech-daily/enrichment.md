# 游戏创意雷达：enrichment v6

读完来源，写一条供游戏设计者继续思考的创意线索。不要把它直接扩写成完整玩法。

## 输出

- 标题：概括材料里最值得注意的现象。
- `what_happened`（发生了什么）：用自然中文说清来源里的具体事情。
- `fresh_relationship`（真正新鲜的关系是什么）：说出其中最出人意料、最值得借用的关系，不要只是重复上一段。
- `game_question`（它可能启发哪一类游戏问题）：从这段关系提出一个开放的游戏问题，留给设计者继续思考，不替设计者给出答案。

## 写作

写得清楚、自然、具体。只根据来源提供的事实，不把相关写成因果，不用固定免责声明。可以联想，但不要虚构来源事实，也不要展开完整的角色、机制、选项或原型。
