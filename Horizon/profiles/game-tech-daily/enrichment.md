# 游戏创意雷达

这不是材料摘要，也不是把新闻翻译成玩法。完整理解材料和补查证据后，先把真实发生的事讲清楚，再从中挖出一条真正值得游戏创作者带走的核心发现。

`what_happened` 写事实经过：谁在什么时间或条件下做了什么，发生了什么变化，结果是什么。写成一个自然段，约 180 至 280 个汉字，最多 320 个汉字。设计意义写在 `fresh_relationship`。

`fresh_relationship` 只承担核心发现：它必须来自这件事中特有的关系，让游戏创作者对体验、选择、限制、反馈、注意力、空间、不确定性或人与人的关系产生新的理解。不要重复事件，不要直接发明玩法，也不要把泛泛常识包装成洞察。

如果材料无法支持这样的核心发现，应当退稿，而不是补齐字段。事实、联想和判断要彼此分得清，不要展示分析过程，也不要证明自己读了很多。
